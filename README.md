# Разбор

Диспетчер внутренних обращений для вуза. Студенты и сотрудники пишут в учебный офис,
деканат, бухгалтерию, IT-поддержку. «Разбор» собирает обращения в одну очередь, определяет
тему, срочность и риск жалобы, направляет в нужное подразделение и готовит черновик ответа
по регламентам вуза. Черновик проверяет код, оператор правит и отправляет, руководитель
видит повторяющиеся причины обращений.

Проект участвует в треке «Эффективность 360» Академии Финтеха 2026.

## Что умеет MVP

- Очередь обращений из почты, личного кабинета, Telegram-бота и бумажных заявлений.
- Разбор одним вызовом модели: тема, подразделение, срочность, риск жалобы, причина,
  ссылки на факты базы знаний и черновик.
- Проверка черновика кодом (`razbor/checks.py`): нет заглушек и лишних обещаний, даты
  и суммы взяты из обращения или регламента, есть ссылка на регламент и следующий шаг.
  Неизвестные подразделения и темы код исправляет сам.
- Экран оператора: можно сменить подразделение, поправить черновик и отправить.
- Панель руководителя: темы, открытые по подразделениям, срочные, риск жалобы,
  повторяющиеся причины, доля ответов без правок, переадресации, время работы оператора.
- Метрика ценности: при отправке сервис считает, сколько черновика осталось в ответе
  (`difflib`), и сколько секунд оператор работал над обращением.

## Как устроено

```
обращение -> модель (JSON) -> checks.route: допустимые тема и подразделение
                           -> checks.draft: проверки черновика
          -> оператор правит и отправляет -> метрики в SQLite -> панель
```

- Только стандартная библиотека Python 3.11+ и SQLite, без зависимостей.
- Модель в OpenAI-формате: адрес, ключ и модель задаются переменными `AI_URL`, `AI_KEY`,
  `AI_MODEL`. Российская или локальная модель (YandexGPT, GigaChat через совместимый шлюз,
  vLLM, Ollama) подключается без правки кода.
- Подразделения, темы и база знаний вуза в `razbor/kb.py`. В пилоте файл заменяется
  регламентами конкретного вуза.
- Дневной лимит вызовов модели `RAZBOR_DAY_LIMIT` (по умолчанию 300).

## Запуск

```
python3 -m venv .venv && ./.venv/bin/pip install ruff mypy pytest
./.venv/bin/python -m razbor.app --seed data/seed.json      # синтетические обращения
AI_KEY=... ./.venv/bin/python -m razbor.app --analyze-all   # разобрать моделью
AI_KEY=... ./.venv/bin/python -m razbor.app                 # http://127.0.0.1:8097
```

Проверки: `ruff check .`, `mypy razbor tools`, `pytest -q`.

## Данные

`data/seed.json` содержит синтетические обращения вымышленного вуза: имена и группы
придуманы. Реальные обращения в демо не используются.
